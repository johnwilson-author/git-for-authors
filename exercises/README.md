# Exercise files

Starting files for the Try it boxes. Each folder has its own README with the
steps, so you can work from the exercise rather than from the book.

| Folder | Chapter | What it's for |
|---|---|---|
| `ch05-first-repo/` | 5.6 | The five-minute walkthrough, three commits |
| `ch08-find-the-paragraph/` | 8.6 | Search, recovery, and word-level diffs |
| `ch12-conflict/` | 12.7 | A deliberately conflicted file, ready to resolve |
| `ch14-stash/` | 14.5 | Park and retrieve uncommitted work |
| `ch29-editorial-round/` | 29.6 | The DOCX round-trip |
| `ch39-backup/` | 39.6 | Bundle, restore, and build |

## How these are meant to be used

Each folder is **not** a Git repository. It's a set of files. The exercise's
README tells you what to run and in what order, and most of them begin with
`git init`.

That's deliberate. Chapter 5's whole point is that you make a repository
yourself; handing you one with a history would remove the lesson.

## The rule

Nothing here can break anything. Every exercise is reversible, and the ones
that involve destructive commands say so and tell you how to recover.
