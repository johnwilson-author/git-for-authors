# Research (not tracked)

This folder is in `.gitignore`. It exists on your machine and Git ignores it
entirely.

Put scans, photographs, downloaded documents, and anything else you consult
here. Chapter 27.1 explains why: this is working material rather than part of
the book, and a folder of forty 5 MB scans would bloat the repository
(Chapter 10.2).

## The exception

A source you could never obtain again — a letter, a document from a
freedom-of-information request, a photograph that is part of the argument — is
worth committing. Remove `research/` from `.gitignore`, add the file, and
commit it with a message that says why it's kept.

The test, from Chapter 27.1: would losing it cost you work you can't redo?
