# Maps

Shared images for the series. Copy them into each book's `assets/` folder
rather than linking across repositories — Chapter 27.4 explains why.

Name them `[series-slug]-[description].[ext]`:

- `salt-house-world-map.png`
- `salt-house-town-detail.png`

If the maps are large, set up Git LFS first (Chapter 27.2).
