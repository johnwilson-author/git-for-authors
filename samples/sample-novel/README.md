# The Salt House

A sample novel, used as the worked example throughout the book.

## Status

Sample. Not a real book. Do not submit it to anyone.

## What to look at

- `chapters/01.md` — headings only, no front matter, a scene break, an HTML
  comment
- `chapters/02.md` — a shorter chapter
- `chapters/03.md` — a chapter with two scene breaks
- `notes/characters.md` — the shape a character file takes
- `notes/timeline.md` — settled dates
- `metadata.yaml` — the metadata file every build reads
- `blurb.md` — three lengths and a notes section

## Build

`./build.sh` or `.\build.ps1`. No cover and no reference document, so the build
skips both and tells you it has.
